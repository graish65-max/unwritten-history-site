Privacy Policy

Last updated September 18, 2026

Unwritten History Publisher connects to the @unwrittenhistoryyt TikTok account to publish the Unwritten History video series. This policy explains what data the application accesses and how it is used.

1. Data accessed

Through TikTok's Login Kit and Content Posting API, the application accesses:

  • Basic profile info for the connected account (open id, display name, avatar) via the user.info.basic scope, used only to confirm which account is authorized.
  • The ability to upload and publish video content to that same account via the video.publish and video.upload scopes.

2. Data we do not collect

The application does not access data belonging to any other TikTok user, does not collect analytics on viewers, does not use TikTok data for advertising, and does not sell, share, or transfer any data to third parties.

3. Data storage

Access and refresh tokens for the connected account are stored securely to allow scheduled publishing to run without manual intervention. They are transmitted only to TikTok's own API endpoints.

4. Data retention and deletion

Access can be revoked at any time from TikTok's account settings (Manage apps and devices), which immediately invalidates any stored tokens.

5. Contact

Questions about this policy can be directed to the operator via the @unwrittenhistoryyt account.
